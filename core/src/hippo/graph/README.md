# Knowledge Graph

**Status:** Planned; this folder contains documentation only.

Own shared knowledge graph operations and queries for the desktop graph viewer and agent access. Build on captured notes and derived data, preserving the connection back to source documents.

Coordinate with User Notes Storage for current note data and with memory management for later agent-memory relationships. Graph extraction, entity resolution, and the graph schema remain future design work; no graph database is selected or installed here.

The viewer belongs in the desktop app. Shared graph behavior belongs in this component.

See [core infrastructure](../../../../docs/architecture/core.md) for the current package and CLI.
